# apps/mobile

The Khushu Android app (Expo, Continuous Native Generation). Licensed under GPL-3.0-or-later; see the repository root `LICENSE` and `LICENSING.md`.

- Android only for now. Expo Go is not supported: the app needs the native engine (`modules/khushu-engine`), so use a development build.
- `android/` and `ios/` are generated by `expo prebuild` and are not committed.

## Develop

From the repository root, after `pnpm install`:

```sh
cd apps/mobile
pnpm prebuild                 # expo prebuild -p android --clean
pnpm android                  # build and install the dev build on a phone or emulator
pnpm start                    # Metro for the dev build
```

Needs JDK 17 and the Android SDK (`ANDROID_HOME`).
